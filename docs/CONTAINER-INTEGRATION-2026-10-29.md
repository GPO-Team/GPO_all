## Непройденный физический сценарий

`npm run test:container` не прошёл полностью в двух независимых запусках:
во втором прогоне браузер не открывался, сбой повторился. После выполнения маршрута,
перезапуска route и проверки отмены после перезапуска simulator перенос
DEMO_BOX остановился на стадии `lifting`, progress 28, с `grip_lost` и
`holding_for_recovery`. Контакты обоих пальцев стали нулевыми; коробка
оставалась на полу. Тест не ослаблялся и успешным не считается.

Перед переносом база находилась около `(0.0001, 0.9508)`, yaw `1.6143` рад;
при потере захвата — около `(1.0734, 0.2220)`, yaw `-0.5982` рад.
Причина срыва захвата в этом сценарии пока не установлена. Геометрия и
контроллер при объединении не менялись; это не доказывает причину сбоя.
Серия 10/10 из [отчёта исправления](MANIPULATOR-GRIP-FIX-2026-10-29.md)
относится к другому сценарию — независимым запускам Webots с новым миром.
Последующий перенос PICK_BOX в этом контейнерном тесте не выполнялся.

Для повторения нужны свободные порты 8080, 9001, 9002, 9003 и 1234:

```powershell
npm run start:container -- --cpu
docker compose -p gpo-full -f compose.yaml -f compose.simulator.yaml down
npm run test:container
```

Остановка выше сохраняет пользовательские тома. Сам тест создаёт отдельный
временный Compose-проект и удаляет только свои контейнеры и тома. При отказе
диагностика записывается в `output/container-smoke-failure.json`.
