# Перенос веб-дизайна на dev/nimmwee

Основа: `origin/dev/nimmwee`, коммит `ad2ef0e`.
Дизайн перенесён из локальной рабочей версии `GPO_all-work`.
Контроллер Webots, нативный solver и обновлённая логика манипулятора взяты из dev/nimmwee.

## Изменения интерфейса

- Компактное меню с разделами «Маршрут», «Зоны», «Покрытия», «Энергия» и сворачиваемыми панелями.
- Вместо кнопок «Добавить на карту» выбор раздела сразу включает соответствующий тип точек, включая выход из режима перемещения карты.
- Подпись «Очистить маршрутные точки» исправлена.
- Очистка отдельной запретной зоны или зоны покрытия недоступна, пока в ней нет точек.
- На карте показаны размеры 44 × 34 м, шаг сетки 1 м и линейка масштаба, которая пересчитывается при масштабировании и изменении размера окна.
- Бирюзовый след лидара управляется переключателем «Карта и след лидара» независимо от камеры и маршрута. Свободные ячейки камеры показаны светло-фиолетовым цветом.
- Запас энергии ограничивается максимумом 10 000 прямо при вводе и вставке, без ожидания потери фокуса.
- Раскрывающиеся списки получили стрелки, подсветку и видимую подсказку «Раскрыть»; детали точек посещения доступны с клавиатуры.
- Управление переносом объекта и восстановлением манипулятора сохранено. Форма переноса раскрывается в разделе «Маршрут», статус переноса остаётся видимым при переключении разделов.

## Запуск

Для интерфейса: `npm ci`, затем `npm run dev` или `start-ui-windows.cmd`.
Для полного стенда используйте инструкции README.md и docs/COMPATIBILITY.md.

- `npm run lint` — успешно.
- `npm test -- --maxWorkers=2` — 116 файлов, 349 тестов успешно.
- `npm run build` — успешно.
- В браузере проверены постановка точек через разделы меню, блокировка очистки пустой зоны, ограничение поля энергии и отображение метража карты.

Исполнение миссий в Webots в рамках этой проверки не запускалось.
